# Правка HTML

Редактор HTML-документов в браузере для тех, кто не знаком с HTML. Открываешь файл, кликаешь по тексту, правишь как в Google Docs, скачиваешь исправленную копию.

**Работает без установки и без сервера:** один файл `index.html`, открывается двойным кликом или через GitHub Pages.

## Как работать

1. Перетащи `.html` в окно (или **Файл → Открыть**).
2. Кликни по тексту и печатай. Над текстом появится панель:
   - **Ж К Ч З**, списки, выравнивание, ссылка, очистка формата;
   - **цвет текста и фона** — только из палитры самого документа, фирменный стиль не ломается;
   - **меню блока** (например, «Строка ▾») — выбор уровня (ячейка → строка → таблица → раздел), копия ниже, новый ниже, переместить, удалить.
3. `Ctrl+S` — скачать исправленный файл. Оригинал не меняется.

## Возможности

- **Конструктор** — «+ → Новый документ» предлагает заготовки: пустой, лендинг, отчёт, обучение, с выбором цвета акцента. Во вкладке «Блоки» справа — 22 блока: клик вставляет после выделенного места, можно перетащить в нужное место документа. Блоки подстраиваются под цвет документа (в шаблоне Билайна становятся жёлто-чёрными).
  - **Основа и текст:** обложка, заголовок раздела, разделитель, абзац, список, выноска (важно / совет / внимание), цитата.
  - **Сетка и медиа:** карточки, колонки (внутрь можно класть другие блоки), таймлайн, таблица, картинка с подписью, видео (YouTube, RuTube, Vimeo), кнопки.
  - **Интерактив:** вкладки, аккордеон, карусель, всплывающее окно, анимированные счётчики, график из таблицы (столбцы или кольцо), тест с проверкой ответа, чек-лист с прогрессом (запоминается в браузере читателя).
  - Над выделенным блоком появляются его действия: «+ вкладку / слайд / карточку…», «Верный ответ» в тесте, «Столбцы / Кольцо» у графика, тип выноски, ссылка на видео.
  - Интерактив работает через один небольшой скрипт `<div id="hed-kit">` в конце файла. В редакторе всё видно и правится без него: вкладки стоят друг под другом, данные графика — таблицей; живой вид — в «Предпросмотре». Неиспользуемые стили блоков убираются при сохранении.
- **Вкладки, как в браузере** — каждый открытый файл в своей вкладке со своей историей правок, исходником и сравнением. На вкладке — название страницы (`<title>`) и её иконка; двойной клик — переименовать, клик по иконке активной вкладки — заменить. Вкладки перетаскиваются, по правому клику: переименовать, сменить/убрать иконку, сохранить, дублировать, закрыть, закрыть другие, закрыть справа. Точка вместо крестика — есть несохранённые правки.
- **Открытие** — `Ctrl+O`, кнопка «+», меню «Файл» или перетаскивание файлов прямо в окно (в том числе поверх открытого документа). Можно сразу несколько. Уже открытый файл не дублируется — редактор переключится на его вкладку. «+» → «Новый пустой документ» создаёт чистую страницу с базовой вёрсткой.
- **Восстановление вкладок** — если закрыть редактор, при следующем открытии он предложит вернуть все вкладки вместе с несохранёнными правками (хранится в `localStorage`, около 5 МБ на всё).
- **Навигация по странице** — кнопка «Навигация»: редактор собирает меню из заголовков и вставляет в файл. На выбор и в любой комбинации: липкое меню сверху с подсветкой текущего раздела, точки сбоку, кнопка «Оглавление», полоса прогресса + «Наверх». Цвет акцента — из палитры документа. При печати скрывается, уважает `prefers-reduced-motion`.
- **Предпросмотр** — страница так, как её увидит читатель: с анимациями и работающей навигацией.
- **Перетаскивание блоков** — ручка ⋮⋮ слева от выделенного блока; перенос среди соседних блоков (строки — внутри таблицы, пункты — внутри списка).
- **Вставка из буфера** — скриншот по `Ctrl+V` становится картинкой (большие ужимаются до 1600 px); строки из Excel / Google Таблиц заполняют таблицу начиная с текущей ячейки, недостающие строки добавляются.
- **Проверка документа** — вкладка «Проверка»: незаполненные `{{поля}}`, битые картинки, картинки без описания, ссылки на несуществующие разделы, пустые блоки, повторяющиеся id, пропуски уровней заголовков, устаревшая навигация. Многое исправляется одной кнопкой.
- **Сохранение прямо в файл** — в Chrome и Edge, если файл открыт через «Файл → Открыть» или перетаскиванием, `Ctrl+S` перезаписывает исходник (с подтверждением). В остальных браузерах — скачивание копии.
- **Мои блоки** — меню блока → «Сохранить в мои блоки». Блок появляется сверху во вкладке «Блоки» и вставляется в любой документ, как обычный. Библиотека хранится в браузере; «Выгрузить» / «Загрузить» передают её коллегам одним `.json`.
- **Заметки для ревью** — 💬 на панели над выделенным местом. У места появляется метка, во вкладке «Заметки» — список с ответами, «Решено» и удалением. Заметки хранятся в самом файле (`<script type="application/json" id="hed-notes">` + атрибуты `data-note-anchor`) и невидимы для читателя; «Файл → Скачать чистовик» убирает их. Открытые заметки видны и в «Проверке».
- **Предпросмотр на устройствах** — переключатель ПК / Планшет (820 px) / Телефон (390 px).
- **Справка** — кнопка «Справка» или `F1`: быстрый старт, все функции по разделам, горячие клавиши.
- **Размер мышью** — у выделенной картинки или блока появляются ручки: справа — ширина, снизу — высота, в углу — обе. Ширина пишется в процентах от родителя (на телефоне блок остаётся резиновым) и прилипает к 25 / 33 / 50 / 66 / 75 / 100 % (Alt — без привязки); у карточек внутри сетки — в пикселях. Двойной клик по ручке — сбросить. У картинки есть выравнивание: слева / по центру / справа.
- **Два документа рядом** — кнопка «Рядом» над документом, «Открыть рядом» по правому клику на вкладке или перетащить вкладку на документ. Оба редактируются: клик по документу делает его активным. Разделитель тянется (двойной клик — пополам), «⇄» меняет местами, «⇅ Вместе» прокручивает оба синхронно. В меню блока появляется «Копировать в соседний документ» — блок со всем оформлением переносится одним кликом.
- **Удаление с отменой** — после удаления всплывает «Отменить»; для крупных блоков (раздел, таблица) — ещё и подтверждение.
- **История** — `Ctrl+Z` / `Ctrl+Y` (отдельных кнопок нет), список правок с переходом к любой точке.
- **Сравнение** — вкладка рядом с историей: что изменилось относительно исходника, с подсветкой в документе.
- **Вкладка браузера** — название (`<title>`) и иконка (favicon) правятся в полоске над документом.
- **Найти и заменить** — `Ctrl+F` / `Ctrl+H`, подсветка совпадений, «Заменить все».
- **Орфография** — подчёркивание ошибок (словарь браузера).
- **PDF** — `Ctrl+P` или **Файл → Сохранить как PDF**.
- **Масштаб** — −/+, 100%, «По ширине».
- **Для разработчика** (переключатель в шапке) — вкладка «Код»: стили выделенного элемента, его классы и HTML, CSS документа. Всё попадает в историю и отменяется.

## Как устроено

- Документ открывается в `iframe` с `sandbox` без `allow-scripts` — скрипты из файла не выполняются.
- Навигация — один блок `<div id="hed-nav">` в начале `body` со своими стилями и небольшим скриптом. Разметка статична, поэтому видна и без JS; скрипт добавляет подсветку текущего раздела и анимации. Перед сохранением меню автоматически подстраивается под заголовки.
- Предпросмотр — отдельный `iframe` с `allow-scripts`, но без `allow-same-origin`: доступа к редактору у него нет, а все скрипты, кроме навигации, вырезаются вместе с `on*`-обработчиками и `javascript:`-ссылками.
- Редактируется только блок, по которому кликнули (`contenteditable` ставится точечно); вставка — только чистый текст.
- Форматирование — `document.execCommand`; цвета через `styleWithCSS`, поэтому в файл пишутся `<span style="color:…">`, а не `<font>`.
- История — снимки `body`, `<title>`, favicon и `<style>` из `head`.
- Вкладки — у каждой свой скрытый `iframe`, поэтому переключение мгновенное, а прокрутка и история сохраняются. Глобальное состояние редактора — это состояние активной вкладки; при переключении оно откладывается в объект вкладки и подменяется.
- Служебные атрибуты `data-hed-*` и стиль `#hed-style` вычищаются при сохранении.

## Ограничения

- После восстановления вкладок связь с файлом на диске теряется (браузер не даёт сохранить её в `localStorage`): `Ctrl+S` скачает копию. Чтобы снова сохранять прямо в файл — открой его заново.

- Поиск находит текст только внутри одного текстового узла (фраза, разбитая разметкой, не найдётся).
- Ресурсы по относительным путям (`img/logo.png`, `style.css`) в редакторе не отображаются — встраивайте их. В сохранённом файле пути не меняются.
- Страницы, которые строятся JavaScript'ом, редактируются только в той части, что есть в исходной разметке.

## Пример

- `examples/report-template.html` — шаблон аналитического отчёта, на котором можно попробовать редактор.
- `examples/landing.html` — лендинг, собранный из шаблона конструктора: открой в браузере и полистай.
- `examples/report-with-nav.html` — тот же шаблон со всеми видами навигации: открой в браузере и полистай.

# Правка HTML

Редактор HTML-документов в браузере для тех, кто не знаком с HTML. Открываешь файл, кликаешь по тексту, правишь как в Google Docs, скачиваешь исправленную копию.

**Работает без установки и без сервера:** один файл `index.html`, открывается двойным кликом или через GitHub Pages.

## Как работать

1. Перетащи `.html` в окно (или **Файл → Открыть**).
2. Кликни по тексту и печатай. Над текстом появится панель:
   - **Ж К Ч З**, списки, выравнивание, ссылка, очистка формата;
   - **цвет текста и фона** — только из палитры самого документа, фирменный стиль не ломается;
   - **меню блока** (например, «Строка ▾») — выбор уровня (ячейка → строка → таблица → раздел), копия ниже, новый ниже, переместить, удалить.
3. `Ctrl+S` — скачать исправленный файл. Оригинал не меняется.

## Возможности

- **Удаление с отменой** — после удаления всплывает «Отменить»; для крупных блоков (раздел, таблица) — ещё и подтверждение.
- **История** — `Ctrl+Z` / `Ctrl+Y`, список правок с переходом к любой точке.
- **Сравнение** — вкладка рядом с историей: что изменилось относительно исходника, с подсветкой в документе.
- **Вкладка браузера** — название (`<title>`) и иконка (favicon) правятся в полоске над документом.
- **Найти и заменить** — `Ctrl+F` / `Ctrl+H`, подсветка совпадений, «Заменить все».
- **Орфография** — подчёркивание ошибок (словарь браузера).
- **PDF** — `Ctrl+P` или **Файл → Сохранить как PDF**.
- **Масштаб** — −/+, 100%, «По ширине».
- **Черновик** — если закрыть вкладку, редактор предложит восстановить правки.
- **Для разработчика** (переключатель в шапке) — вкладка «Код»: стили выделенного элемента, его классы и HTML, CSS документа. Всё попадает в историю и отменяется.

## Как устроено

- Документ открывается в `iframe` с `sandbox` без `allow-scripts` — скрипты из файла не выполняются.
- Редактируется только блок, по которому кликнули (`contenteditable` ставится точечно); вставка — только чистый текст.
- Форматирование — `document.execCommand`; цвета через `styleWithCSS`, поэтому в файл пишутся `<span style="color:…">`, а не `<font>`.
- История — снимки `body`, `<title>`, favicon и `<style>` из `head`.
- Служебные атрибуты `data-hed-*` и стиль `#hed-style` вычищаются при сохранении.

## Ограничения

- Поиск находит текст только внутри одного текстового узла (фраза, разбитая разметкой, не найдётся).
- Ресурсы по относительным путям (`img/logo.png`, `style.css`) в редакторе не отображаются — встраивайте их. В сохранённом файле пути не меняются.
- Страницы, которые строятся JavaScript'ом, редактируются только в той части, что есть в исходной разметке.

# Правка HTML

Редактор HTML-документов в браузере для тех, кто не знаком с HTML. Открываешь файл, кликаешь по тексту, исправляешь, скачиваешь — разметку и стили сломать нельзя.

**Работает без установки и без сервера:** один файл `index.html`, открывается двойным кликом или через GitHub Pages.

## Возможности

- **Текст** — клик по тексту и печатаешь. `Enter` — готово, `Shift+Enter` — перенос строки. Вставка идёт без чужого форматирования.
- **Строки и блоки** — дублировать, добавить пустой, сдвинуть выше/ниже, удалить. Уровень выбирается в цепочке «Таблица › Строка › Ячейка».
- **Картинки и ссылки** — замена картинки файлом с компьютера, правка alt и адреса ссылки.
- **История** — `Ctrl+Z` / `Ctrl+Y`, список всех правок с переходом к любой точке, «Вернуть исходник» (тоже отменяется).
- **Сохранение** — `Ctrl+S` скачивает исправленную копию, оригинал не трогается. Комментарии и структура файла сохраняются.
- **Черновик** — если закрыть вкладку, при следующем открытии редактор предложит восстановить правки.

## Как устроено

- Документ открывается в `iframe` с `sandbox` без `allow-scripts` — скрипты из файла не выполняются.
- Редактируется только элемент, по которому кликнули (`contenteditable` ставится точечно).
- История — снимки `body`; служебные атрибуты `data-hed-*` и стиль `#hed-style` вычищаются при сохранении.

## Ограничения

- Ресурсы по относительным путям (`img/logo.png`, `style.css`) в редакторе не отображаются — встраивайте их (base64 / inline CSS). В сохранённом файле пути не меняются.
- Страницы, которые строятся JavaScript'ом, редактируются только в той части, что есть в исходной разметке.
